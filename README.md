# 💰 Mon Budget Financier V4

Application mobile de calcul et de simulation budgétaire.

### Calculs automatiques
- revenus mensuels
- charges mensuelles
- épargne mensuelle
- reste à vivre mensuel
- reste hebdomadaire
- reste quotidien
- taux d'épargne
- charges et épargne annuelles
- projections 3 / 6 / 12 mois
- simulation personnalisée

### Gestion
- lignes de revenus, dépenses et épargne
- fréquence mensuelle, annuelle ou hebdomadaire
- catégories
- objectifs d'épargne
- crédits et dettes
- sauvegarde/restauration JSON
- fonctionnement hors connexion après chargement

## GitHub Pages
Dépose `index.html` dans un dépôt GitHub puis active :
Settings → Pages → Deploy from a branch → `main` → `/root`.

Les données restent dans le stockage local du navigateur.
